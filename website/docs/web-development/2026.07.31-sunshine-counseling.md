## Problem 

Sunshine Counseling Services, local counseling and therapy services business, did not have a website. As a 
result, customer  did not have a creditable online presence.

## Solution

I created a business website.  Create a static website is great for businesses that need an online presence
without the maintainance overhead of a WordPress or content management system website.

With this particular setup, updates to the website can be made in two ways: 

1) via Github using the online editor
2) via VS code or personal computer and committing the changes

Project was started and completed in 2026.

## Technology

* CSS
* HTML
* MkDocs
* Firebase
