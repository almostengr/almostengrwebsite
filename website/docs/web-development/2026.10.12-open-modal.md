With the applications that I build, I like to design patterns so that it easier 
for the user to understand what they are doing. I use Bootstrap for the websites
and applications that I create, as it is at the time of this writing, the default 
styling for the C# MVC applications.

Viewing or read only screens show 
up as full page. In some cases, links or buttons are made available to display 
additional information.  This prevents the page from being too crowded by 
hiding the additional details.

For the create, update, and delete operations, a modal is opened first. Then 
when the user confirms the action or submits the form that was requested, then the operation 
is performed.

At the time of writing, the current version of C# MVC applications that 
I was building used .NET 10, Bootstrap 5, and vanilla JavaScript. 

## The Code

### Javascript

```javascript
const modalContentElement = document.getElementById("modalContent");
const modalCoreElement = document.getElementById("myModal");
const modalElement = new bootstrap.Modal(modalCoreElement, {
    keyboard: false,
    backdrop: 'static',
});

async function loadAndShowModalAsync(url) {
    if (!url || !modalElement || !modalContentElement) {
        console.error("Modal, modal content, or URL is missing.");
        return;
    }

    try {
        const response = await fetch(url);
        if (!response.ok) {
            throw new Error(response);
        }

        modalContentElement.innerHTML = await response.text();
        modalElement.show();
    }
    catch (error) {
        alert("Unable to display form.");
        console.error(error.message);
    }
}

function addModalListeners() {
    document.querySelectorAll(".modalLink")
        .forEach(link => {
            link.addEventListener("click", async function (event) {
                event.preventDefault();
                await loadAndShowModalAsync(link.dataset.url);
            });
        });
}

async function submitModalFormAsync(submitButton) {
    const formElement = modalContentElement.querySelector("form");
    if (!formElement) {
        return;
    }

    const formMethod = formElement.getAttribute("method");
    const formAction = formElement.getAttribute("action");
    const formData = new FormData(formElement);

    try {
        const response = await fetch(
            formAction, {
            method: formMethod,
            body: formData
        });

        if (!response.ok) {
            throw new Error(`HTTP error: ${response.status} ${response.statusText}`);
        }

        const result = await response.text();
        if (result === "" || result === null) {
            window.location.reload();
            return;
        }

        modalContentElement.innerHTML = result;
    }
    catch (error) {
        console.error(error.message);
    }
}

addModalListeners();
```

### Modal HTML

In regards to the HTML, the Modal code provided in the Bootstrap 5 documentation 
is what I use.  In my case, I have the "modalContent" ID attribute added to the div with the "modal-content" class. 

```html
<div class="modal fade" tabindex="-1" id="myModal">
  <div class="modal-dialog">
    <div class="modal-content" id="modalContent">
    </div>
  </div>
</div>
```

With the code above, I have my controller load the necessary partial view. The code above is stored 
in the "_Layout.cshtml".  That way it is always available and only the contents inside the modal have to be loaded when called and not the entire modal.

Below is how to do a partial view in the controller.

```csharp
public IActionResult Edit()
{
    var resource = _queryService.Get();

    RunModeViewModel model = new(resource);
    return PartialView("_Edit", model);
}
```

When there is an error with the form, the results are displayed in the modal. When the form submission 
is successful, the page reloads. 

### Submit Button

The form does not have a HTML submit button. Instead the button is configured to call a Javascript function 
that will submit the form using the Javascript Fetch API. Then that response is processed accordingly.

Below is the code to use to submit the form.

```html
<div class="modal-footer">
    <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Cancel</button>
    <button type="button" class="btn btn-primary" onclick="submitModalFormAsync(this)">Save Changes</button>
</div>
```

### Modal Links

Modal links are used on the page where a link should open the modal. 

```html
<a href="#" class="modalLink" data-url="/profiles/edit/@Model.Id">Edit</a>
```

In the example above, the ```data-url``` attribute is passed to the javascript code to know which 
URL to call to populate the modal content. Not setting this attribute will result in the modal not opening 
and throwing an error.

## Conclusion

Be sure to have the Javascript files that contain the above code, at the bottom of your page. If not, 
when the page loads, not all elements will be available which will result in Javascript errors.
